# Interactive Plays

This folder contains interactive side-by-side scenes for VRM character evaluation and cinematic playback.

## Available Scenes

*   **[Original Side-by-Side Scene](side_by_side_scene.html)** - Evaluates the default models from the traffic escalation scene.
*   **[MetaHuman Side-by-Side Scene](side_by_side_metahuman.html)** - Features the MetaHuman VRM 1.0 model for high-fidelity facial animation testing.

## Local Development

If you are running the project locally, start the server from the root directory:

```bash
node serve.mjs
```

Then visit:
* http://localhost:3500/plays/side_by_side_scene.html
* http://localhost:3500/plays/side_by_side_metahuman.html
